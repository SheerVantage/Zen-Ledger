# Zen Ledger - The Insight (Analysis)

## Purpose
Monthly reflection.

## Layout
Horizontal swiping cards (Stories format) for different metrics.

## Key Elements
- **Metric Cards:** 300px height.
    - **Headline:** "Dining out is down 12%."
    - **Visual:** Simple bar chart using rounded pillars. Only showing top 3 categories.
- **Narrative Summary:** Bottom section.
    - **Text:** "You saved $450 this month, mostly by cutting back on subscriptions. Nice work."
    - **Style:** Large, readable body text (Quicksand 18px).

## States
- **Insufficient Data:** "Gathering wisdom... check back in a few days."
