# Technology Stack

## Core Technologies
- **Svelte 5 (SvelteKit):** A highly performant and flexible frontend framework for building modern web applications.
- **TypeScript:** A strongly typed language that builds on JavaScript to improve developer productivity and application stability.
- **Vite:** A lightning-fast build tool and development server for modern web development.

## Styling & Design
- **Tailwind CSS:** A utility-first CSS framework for rapid UI development and consistent design.

## Testing & Quality Assurance
- **Playwright:** A robust testing framework for reliable end-to-end testing across all modern browsers.
- **Svelte-Check:** A tool for performing static analysis on Svelte projects.

## Additional Tools
- **npm:** The default package manager for managing dependencies.
